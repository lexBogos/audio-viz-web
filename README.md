# audio-viz web

Браузерная версия audio-viz: абстрактный аудиовизуализатор, который целиком работает у посетителя. Рендер идёт на его GPU через WebGPU, анализ трека — в WebAssembly. Сервер только отдаёт статические файлы.

**Сайт:** https://lexbogos.github.io/audio-viz-web/

```
трек ─ Web Audio (decodeAudioData) ─▶ wasm: FFT-анализ ─▶ wasm + WebGPU: шейдер-пресет ─▶ bloom ─▶ canvas
         └─▶ воспроизведение (AudioContext) ── позиция каждый кадр ──┘
```

## Что умеет
- **трек**: выбор файла или перетаскивание (аудио и видео, всё, что декодирует браузер); воспроизведение, пауза, перемотка, полноэкранный режим;
- **шкала трека** с волной: тяните, чтобы выделить фрагмент, края двигаются, клик — перемотка, двойной клик — весь трек, колесо — масштаб, Shift+колесо — сдвиг; «повтор» крутит фрагмент по кругу;
- **13 пресетов** и **сцены**: с начала сцены играет другой пресет, переход плавный, длина настраивается (голубые флажки на шкале);
- **ползунки** цвета, движения и эффектов: свечение, виньетка, зерно, аберрация, тряска, рывок зума, вспышка на бит, глитч, VHS, вращение оттенка;
- **ключевые кадры** («Динамика»): между ключами все настройки плавно перетекают, и в превью, и в экспорте (жёлтые ромбы на шкале: клик — перейти, тянуть — сдвинуть, правый клик — удалить);
- **фрагмент** с появлением и затуханием — видно и слышно уже в превью;
- **фон** (картинка под визуализацией: яркость, прозрачность визуализации, пульс на бас), **обложка в центре** (круг с картинкой — по умолчанию из тегов MP3/FLAC/M4A — и кольцо спектра), **полоса прогресса**;
- **текст**: до 8 надписей с любым шрифтом, местом, размером, цветом, тенью, анимацией появления и показом в своём отрезке; надпись можно перетащить прямо в кадре; **логотип**;
- **экспорт** выбранного фрагмента:
  - видео MP4 — H.264, HEVC, AV1 или VP9 (в списке только то, что умеет браузер), звук AAC или Opus; кадр 16:9, 9:16 или 1:1, 720p–4K, 24–60 к/с, три уровня битрейта. Кадры рендерятся по одному, быстрее реального времени и без пропусков, превью на это время встаёт на паузу, чтобы не отнимать GPU. В Chrome/Edge файл пишется прямо на диск, в остальных браузерах собирается в памяти и скачивается;
  - только звук — WAV или M4A;
  - кадр PNG в разрешении экспорта (например, обложка для видео);
  - «громкость под YouTube» — выравнивание до −14 LUFS (BS.1770), пики не выше −1 дБ;
- **превью** само снижает разрешение, если GPU не успевает, и поднимает обратно; на паузе кадры не перерисовываются, пока ничего не меняется;
- **проект**: настройки сами сохраняются в браузере; «Сохранить…» пишет файл `.avz.json` со всеми настройками и картинками;
- клавиши: `Space` — пауза, `←`/`→` — 5 с (с `Shift` — 1 с), `N`/`P` — пресет, `[` `]` — границы фрагмента, `Home`/`End` — к ним, `L` — повтор, `K` — ключ, `F` — во весь экран, `⌘/Ctrl+S` — сохранить проект.

## Pro
Всё работает бесплатно. В бесплатной версии в правом нижнем углу видео и PNG стоит маленький знак «◆ audio-viz»; Pro его убирает, больше ничем не отличается. Об этом напоминает одна строка в панели экспорта, без всплывающих окон.

Ключ Pro — `AVZ1.<данные>.<подпись>`, подпись Ed25519. Страница проверяет её открытым ключом из [www/license.js](www/license.js), без сервера и без отправки данных. Ключи выдаёт [scripts/license.mjs](scripts/license.mjs):
```bash
node scripts/license.mjs keygen
```
```bash
node scripts/license.mjs issue "заказ 1042" 1
```
`keygen` создаёт пару ключей один раз (закрытый — в `~/.config/audio-viz/license-private.pem`, вне репозитория) и печатает открытый для `PUBLIC_KEY` в `www/license.js`. `issue` печатает ключ; второй аргумент — срок в месяцах (подписка), без него ключ бессрочный. Ссылка на страницу оплаты — `CHECKOUT_URL` в `www/license.js`; пока она пустая, кнопки «Купить» нет, и ключ можно только ввести.

Нужен браузер с WebGPU: Chrome/Edge 113+, Safari 26+, Firefox 141+ (Windows).

## Сборка
Нужны Rust с целью wasm и `wasm-bindgen-cli` той же версии, что в `Cargo.toml`:
```bash
rustup target add wasm32-unknown-unknown
cargo install wasm-bindgen-cli --version 0.2.130 --locked
```
```bash
./build.sh
python3 -m http.server 8173 --directory www
```
Затем откройте http://localhost:8173.

При пуше в `main` GitHub Actions собирает модуль и публикует `www/` на GitHub Pages.

## Устройство
- `src/lib.rs` — API для страницы: WebGPU на canvas, анализ трека, пресеты и сцены, ползунки и ключевые кадры, картинки, текстовый слой, отрисовка превью, экспорт кадров, снимок PNG, проект в JSON.
- `src/gpu.rs`, `src/analysis.rs`, `src/presets.rs`, `src/animation.rs`, `shaders/` — рендер, анализ, пресеты и ключевые кадры (копии из десктопной версии; в `gpu.rs` добавлено обновление текстового слоя без пересоздания целей рендера).
- `www/main.js` — страница: декодирование и воспроизведение через Web Audio, интерфейс, адаптивное превью, проект.
- `www/timeline.js` — шкала трека; `www/overlay.js` — надписи, логотип и водяной знак (Canvas 2D → один RGBA-слой, анимация на GPU); `www/media.js` — картинки и обложки из тегов; `www/license.js` — проверка ключа Pro.
- `www/export.js` — экспорт: wasm рендерит кадр в размере экспорта и переводит его в NV12 (`shaders/nv12.wgsl`), WebCodecs кодирует, [mp4-muxer](https://github.com/Vanilagy/mp4-muxer) (`www/vendor/`, MIT) собирает MP4.

## Свои пресеты
Пресет — WGSL-файл в `shaders/presets/` с одной функцией, его нужно добавить в список в `src/presets.rs`:
```wgsl
fn scene(uv: vec2<f32>, frag: vec2<f32>) -> vec3<f32> { ... }  // линейный HDR-цвет
```
Доступные данные: `U.bass`, `U.mid`, `U.high`, `U.level`, `U.beat` (0..1), `U.energy`, `spec(x)` (спектр из 64 полос). Описание полей — в [shaders/prelude.wgsl](shaders/prelude.wgsl).
